## 📋 Installation

1. Téléchargez le fichier JAR depuis le lien ci-dessus
2. Placez-le dans `.minecraft/mods/`
3. Assurez-vous que NeoForge 21.1.172+ est installé
4. Lancez Minecraft avec le profil NeoForge
5. Testez avec `/smartmobs debug`
