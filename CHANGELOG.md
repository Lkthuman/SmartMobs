# Changelog - SmartMobs

## [1.0.0] - 2026-10-07

### ✨ Features
- ✅ Système d'apprentissage des mobs
- ✅ Détection du comportement du joueur
  - Utilisation de l'arc/arbalète
  - Combat au mêlée
  - Construction
  - Combat en hauteur
- ✅ Système de mémoire persistant
- ✅ 4 niveaux d'adaptation (LOW, NORMAL, SMART, VERY_SMART)
- ✅ Stratégies d'adaptation :
  - Anti-Ranged (Éviter les projectiles)
  - Anti-High-Ground (Gérer les hauteurs)
  - Climb (Monter)
  - Cover (Chercher un abri)
- ✅ Commandes de debug et administration
- ✅ Configuration flexible
- ✅ Support multijoueur
- ✅ Compatible vanilla Minecraft

### 🐛 Bug Fixes
- Pas de bugs critiques identifiés en v1.0.0

### 🔧 Technical
- Minecraft 1.21.1 / NeoForge 1.21.1
- Java 21
- Gradle build system
