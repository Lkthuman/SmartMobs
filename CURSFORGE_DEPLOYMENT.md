```

```

### Description Complète
```
Smart Mobs adds intelligent, learning AI to Minecraft mobs. 
Mobs observe your behavior and gradually adapt their strategy.

Features:
- Real adaptive AI (not just stat buffs)
- 9 different behavioral strategies
- 16 visible learning animations
- Iron Golem can build to reach high players
- 11 supported mobs
- Fully configurable difficulty
- Multiplayer compatible
- Performance optimized (zero lag)

Example: Stand on a 3-block tower and attack an Iron Golem. 
After 30-60 seconds, it will start finding blocks and building 
up to reach you. It genuinely learns!
```

## 🚀 Étapes de Publication

### 1. Créer le Projet sur CurseForge
1. Allez sur https://cursemaven.com
2. "Créer un nouveau mod"
3. Sélectionnez "Minecraft Java"
4. Remplissez les métadonnées

### 2. Upload du JAR
1. "Ajouter une version"
2. Version: 1.0.0
3. Minecraft Version: 1.21.1
4. Loader: NeoForge 21.1.172+
5. Upload `smartmobs-1.0.0.jar`
6. Type de release: Release

### 3. Description et Détails
1. Copier la description longue
2. Remplir le changelog
3. Ajouter catégories
4. Sélectionner environnements

### 4. Visuels (optionnel mais recommandé)
1. Upload icon 256x256
2. Upload screenshots 1920x1080
3. Upload banner 1920x1080

### 5. Soumettre pour Review
1. Vérifier tous les détails
2. Cliquer "Publish"
3. Attendre la review CurseForge (~24h)
4. Mod publié!
