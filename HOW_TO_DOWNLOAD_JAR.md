# 📥 Guide de Téléchargement - Smart Mobs JAR v1.0.0

## 🎯 Où Télécharger ?

### **✅ Depuis GitHub Releases (Recommandé)**

1. Allez sur : **https://github.com/Lkthuman/SmartMobs/releases**
2. Trouvez la release **v1.0.0**
3. Téléchargez **smartmobs-1.0.0.jar**

**Lien Direct** :
```
https://github.com/Lkthuman/SmartMobs/releases/download/v1.0.0/smartmobs-1.0.0.jar
```

---

## 📦 Installation (5 minutes)

### **Étape 1 : Installer NeoForge**

1. Téléchargez NeoForge 21.1.172+ depuis : https://neoforged.net/
2. Lancez l'installeur
3. Sélectionnez votre installation Minecraft
4. Cliquez **Install**

### **Étape 2 : Placer le JAR**

```bash
# Windows
C:\Users\YourName\AppData\Roaming\.minecraft\mods\smartmobs-1.0.0.jar

# macOS
~/Library/Application Support/minecraft/mods/smartmobs-1.0.0.jar

# Linux
~/.minecraft/mods/smartmobs-1.0.0.jar
```

### **Étape 3 : Lancer Minecraft**

1. Ouvrez le Launcher Minecraft
2. Sélectionnez le profil **NeoForge**
3. Cliquez **Play**

### **Étape 4 : Tester**

En jeu :
```
/smartmobs debug
```

Vous devriez voir les stats du mob visé.

Une fois installé :

- ✅ Aucun crash au démarrage
- ✅ `/smartmobs debug` fonctionne

## 🐛 Troubleshooting

### Crash au démarrage ?

1. Vérifiez que NeoForge 21.1.172+ est installé
2. Supprimez le JAR et retéléchargez
3. Videz le cache Minecraft : supprimer le dossier `versions`

### Commandes ne fonctionnent pas ?

1. En mode créatif ou avec les permissions
2. Utilisez `/smartmobs` sans arguments pour l'aide

### Performance mauvaise ?

1. Réduisez `adaptationChance` dans la config
2. Augmentez `observationCooldown`
3. Réduisez le nombre de mobs
