# Smart Mobs - Description CurseForge

## 📖 Résumé Court

Les mobs apprennent et adaptent leur stratégie en temps réel ! Découvrez une IA Minecraft révolutionnaire avec des animations visibles qui donnent l'impression que les créatures vous observent et comprennent votre style de combat.

---

## 🎮 Description Longue

### Concept Principal

**Smart Mobs** transforme l'IA Minecraft en quelque chose de **vivant et intelligent**.

Au lieu de simplement augmenter les stats, les mobs vont :
- **Observer** votre façon de combattre
- **Apprendre** vos habitudes
- **S'adapter** avec des stratégies différentes
- **Montrer** visuellement qu'ils apprennent

### Exemple Principal : Le Golem en Hauteur

Imaginez : Vous construisez une tour et attaquez un Iron Golem depuis le sommet.

**Début** → Le Golem tente de vous atteindre normalement  
**Après 30 sec** → Le Golem observe et réfléchit  
**Après 60 sec** → **ADAPTATION DÉVERROUILLÉE !** (particules brillantes)

Et là... **le Golem commence à chercher des blocs autour de lui** 🧱

Il les ramasse, les place un à un, et **grimpe progressivement vers vous**.

C'est RÉEL. C'est VISUEL. C'est **INCROYABLE**.

## 🎯 Les 9 Stratégies

1. **SEEK_COVER** - Chercher une couverture
2. **ANTI_RANGED** - Adapte la distance contre l'arc
3. **ANTI_HIGH_GROUND** - Atteint les joueurs en hauteur
4. **FLANK** - Contourne le joueur
5. **SURROUND** - Encercle le joueur
6. **CLIMB** - Grimpe vers la cible
7. **RETREAT** - Bats en retraite
8. **PATH_REEVALUATION** - Cherche un chemin alternatif
9. **BUILD_UP** - Golem construit une tour

## 📝 Installation

1. Téléchargez le JAR
2. Placez dans `.minecraft/mods/`
3. Lancez avec NeoForge 21.1.172+
4. Config auto-générée
5. Profitez! 🎮

---

## 🔧 Configuration

Fichier automatique : `config/smartmobs-common.toml`

```toml
enabled = true
learningSpeed = 3
maxAdaptationLevel = 3
adaptationChance = 70
debugMode = false
```
