# 🎯 Étapes Réelles Pour Publier le JAR en Release GitHub

## **L'IMPORTANT : Tu dois faire ceci toi-même sur GitHub.com**

Je ne peux pas créer automatiquement une release GitHub (l'API ne le permet pas facilement en une seule commande).

Voici comment faire en 2 minutes :

---

## ✅ ÉTAPE 1 : Accéder à GitHub

1. Va sur : **https://github.com/Lkthuman/SmartMobs**
2. Clique sur l'onglet **"Releases"** (à côté de "Code")

---

## ✅ ÉTAPE 2 : Créer une Nouvelle Release

1. Clique sur **"Create a new release"** (ou **"Draft a new release"**)

---

## ✅ ÉTAPE 3 : Remplir les Infos

**Tag version** :
```
v1.0.0
```

**Release title** :
```
Smart Mobs v1.0.0 - Official Release
```

**Describe this release** :
(Copie-colle du fichier RELEASE_BODY.md)

---

## ✅ ÉTAPE 4 : Attacher le JAR

1. Scroll jusqu'à **"Attach binaries by dropping them here or selecting them"**
2. Clique sur le lien ou drag-drop le fichier `smartmobs-1.0.0.jar`

**Le JAR se trouve à** :
- https://github.com/Lkthuman/SmartMobs/raw/releases/smartmobs-1.0.0.jar

OU

- Récupère-le depuis : https://github.com/Lkthuman/SmartMobs/releases (branche `releases`)

---

## ✅ ÉTAPE 5 : Publier

1. Coche **"Set as the latest release"**
2. Clique sur **"Publish release"**

---

## ✅ RÉSULTAT

Après publication :

```
https://github.com/Lkthuman/SmartMobs/releases/tag/v1.0.0
```

Le JAR sera téléchargeable :
```
https://github.com/Lkthuman/SmartMobs/releases/download/v1.0.0/smartmobs-1.0.0.jar
```

---

## 🚀 C'est Fait !

Ta release est maintenant publique et les gens peuvent télécharger le mod ! 🎉
